# Listing Description Generator

A Python script that uses the Claude API to generate 3 real estate listing descriptions in different tones from a single property input.

## Tools
- Python
- Anthropic Claude API

## How it works
Input a property address, bedrooms, bathrooms, and key features. Claude outputs 3 descriptions:
- Luxury: elegant and aspirational
- Friendly: warm and family-oriented  
- Investment: facts-focused and ROI-driven

# Ad Headline Generator

A Python script that uses the Claude API to generate 5 ad headline variants from a single product description.

## Tools
- Python
- Anthropic Claude API

## How it works
Run `ad_headlines.py` with a product description as a command-line argument:

```
python3 ad_headlines.py "A reusable stainless steel water bottle that keeps drinks cold for 24 hours"
```

Claude outputs 5 numbered headline variants.
